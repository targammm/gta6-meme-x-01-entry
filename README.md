delays, leaks and two trailers, and on launch day the poster is suddenly
"sick" all week — while their AI agent pays the rent by winning bounties
on make.fun. The meme picture puts the make.fun ghost in the middle of a
Leonida sunset, holding a sick note next to a circled launch-day calendar.
The post itself is the entry; this repository hands in its address.
The X account and the post stay public until the results are out.
The post: https://x.com/Tarmizi05539333/status/2123585104203379014

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

That copies `POST.json` — the X post's address — into `out/`, where the
grader reads it.
